# STM32F103

Pinout for the `stm32f103-embassy` probe firmware. The default build carries the F103 probe map
shared by the ST-Link/V2-1, the ST-Link V2 clone dongles, and DAPLink STM32F103xB-compliant
boards:

| Signal | Pin |
|---|---|
| SWCLK / TCK | PB13 |
| SWDIO / TMS | PB14 (some boards tie PB12 to the same net) |
| nRESET | PB0 (open-drain) |
| VCOM TX / RX | PA2 / PA3 (USART2) |
| SWO | PA10 (USART1 RX) |
| USB connect | PA15 (high presents the D+ pull-up; unconnected on hard-tied boards) |
| COM LED | PA9 (bicolor: high = red, low = green, floating = off) |
| USB D- / D+ | PA11 / PA12 |

The core runs at 72 MHz from an 8 MHz crystal. The `nanodap` feature selects the nanoDAP V2.3
wiring instead: the D+ pull-up switched from PB15 (active low), a single LED on PC13, JTAG
composed with TDI=PA7 and TDO=PA5, and no SWO route.

Build with `cargo build --release` in the firmware directory, then flash the ELF through the
SWD header (`probe-rs download --chip STM32F103CB <elf>`).
