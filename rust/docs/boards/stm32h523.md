# STM32H523 probe

The `stm32h523-embassy` firmware adapts the ST-Link probe signal map to an STM32H523CE:

| Signal | Pin |
|---|---|
| SWCLK / TCK | PB13 |
| SWDIO / TMS | PB14 |
| nRESET | PB0 (open-drain) |
| TDI | PA7 |
| TDO | PA6 |
| VCOM TX | PA2 (USART2) |
| VCOM RX | PA3 (USART2) |
| SWO | PA10 (USART1 RX) |
| Status LED | PC13 (active low) |
| USB D- / D+ | PA11 / PA12 |

The core runs at 250 MHz from the internal HSI via PLL1; USB is crystal-less (HSI48 + CRS).
The `0x9F` vendor command reboots into the system-memory USB DFU at `0x0BF9_7000`.

The current hardware uses a WeAct STM32H523CE core board. The firmware uses its PC13 LED but does
not depend on the board's HSE oscillator or user buttons; those pins remain available for a future
board-specific composition.

Build with `cargo build --release` in the firmware directory, then flash the ELF through the
SWD header (`probe-rs download --chip STM32H523CE <elf>`).
