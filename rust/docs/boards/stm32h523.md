# STM32H523 probe

The `stm32h523-embassy` firmware uses this signal map on an STM32H523CE:

| Signal | Pin |
|---|---|
| SWCLK / TCK | PB10 |
| SWDIO / TMS | PB15 |
| nRESET | PB0 (open-drain) |
| TDI | PA7 |
| TDO | PA6 |
| VCOM TX | PA2 (USART2) |
| VCOM RX | PA3 (USART2) |
| SWO | PA10 (USART1 RX) |
| Status LED | PC13 (active low) |
| USB D- / D+ | PA11 / PA12 |

PB12, PB13 and PB14 share the SWCLK and SWDIO nets and are held as unpulled inputs; only
`accel-duplex` uses PB14, as its SWDIO pad, with SPI transmit sessions driven from PB15.

The default engine bit-bangs SWD and JTAG from RAM-resident loops; `accel` drives SWD through SPI2
sessions and `plain-bitbang` selects the dap-rs bit-bang engine. `dap-packet-512` advertises a
512-byte DAP packet.

The core runs at 250 MHz from the internal HSI via PLL1; USB is crystal-less (HSI48 + CRS).
The `0x9F` vendor command reboots into the system-memory USB DFU at `0x0BF9_7000`.

The map fits the WeAct STM32H523CE core board; the firmware uses its PC13 LED but not its HSE
oscillator or buttons.

Build with `cargo build --release` in the firmware directory, then flash the ELF through the
SWD header (`probe-rs download --chip STM32H523CE <elf>`).
